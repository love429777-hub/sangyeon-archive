# 🎨 Design Engineering Catalog Design System

디자인공학과의 전문성을 표현하기 위한 전시 도록(Exhibition Catalog) 미학 지침입니다.

## 1. 핵심 감성 (Brand Aesthetic)
- **Precision (정밀성)**: 모노스페이스 넘버링(`№ 01`), 세밀한 분해도, 스펙 테이블
- **Minimalism (절제미)**: 과도한 장식을 배제하고 작품 사진과 3D 렌더의 몰입감을 극대화
- **Editorial (도록 편집)**: 미술관/디자인 비엔날레 도록 같은 여백과 캡션 배치

## 2. 컬러 시스템
- Background: `#0B0C10` (Dark Editorial) 또는 `#F8F9FA` (Clean Gallery)
- Border / Line: `#1F242D` / `#E2E8F0`
- Accent: `#2563EB` (Precision Royal Blue) / `#F97316` (Industrial Safety Orange)
- Badge: Monospace, uppercase, subtle outline
